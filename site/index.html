Open source · Built on Helium · Windows first

Every space is its own world.

Loka is a browser for people with forty tabs open. Sort them into spaces and folders inside folders, then jump between them with one key. Underneath it's Helium: Chromium with Google taken out and uBlock Origin built in.

लोक

loka noun, Sanskrit

A world. A realm with its own light. Old cosmology counts many lokas, each a separate place you can travel to. Loka gives each part of your life a world like that, with its own tabs, its own folders and its own color.

Spaces

Tabs, sorted the way your life already is.

  1. 01

    One space per part of your life.

    Work, school, a side project, the things you read at night. Each space keeps its own pinned tabs, open tabs and color. Ctrl 1 to 9 jumps between them, and the whole window takes on that space's color, so you always know where you are.

  2. 02

    Folders that hold folders.

    Pin a tab and it stays. Group pinned tabs into folders, put a folder inside another, and drag anything anywhere. A class gets a folder. Its group project gets a folder inside that one.

  3. 03

    Pinned tabs stay. Open tabs go.

    Closing a pinned tab only unloads it, so it's still there tomorrow. Tabs under the divider are for right now, and closing one deletes it. Essentials, the icon grid at the top, follow you into every space.

Helium inside

Fast and private, because it's Helium.

Loka doesn't write a browser engine. It's Helium with a new sidebar, and Helium is ungoogled-chromium with the rough edges sanded off. All of this is there before Loka adds a line.

accounts.google.com clients2.google.com update.googleapis.com

No Google inside.

Built on ungoogled-chromium. No Google account, no Google sync, and no usage reports sent anywhere. Even extension installs go through Helium's servers instead of Google's.

uBlock Origin from the first launch.

Helium ships its own build of uBlock Origin, so ads and trackers are gone before you install anything.

Your Chrome extensions work.

Install from the Chrome Web Store like you always have. Same engine, same extensions.

!gh loka github.com/search

!bangs in the address bar.

Type !gh loka or !w Chromium and land on that site's search results.

Tabs sleep when you leave.

Memory Saver is on by default, so forty tabs don't cost forty tabs' worth of RAM.

HTTPS first.

Pages load over HTTPS when the site supports it, and you get a warning before a plain HTTP page.

155

Current Chromium.

Chromium 155 today, updated with every Helium release. Sites work the way they do in Chrome, because underneath it's the same engine.

Why another browser

Arc's idea, on an open engine.

Arc showed that a sidebar of spaces is a better way to hold tabs, then stopped adding features in 2025. Zen carries the idea on Firefox. Loka brings it to Chromium, in the open, with Helium's privacy.

Questions

Fair questions.

When can I use it?

The sidebar works today as a web prototype, the one at the top of this page. The browser build is Helium with Loka's patches still to come. Join the waitlist and you'll get one email when there's a Windows build worth using every day.

Is it free?

Yes. Free and open source under GPL-3.0, with no account needed.

What about Mac and Linux?

Windows comes first. Helium already runs on macOS and Linux, so ports are realistic once the Windows build is solid.

Why not just use Helium?

You should, if you like a classic tab strip. Loka is for people who want vertical spaces and folders. Same engine and the same privacy, with a different way of holding tabs.

Is Loka part of Helium?

No. Loka is an independent project built on Helium's open-source code. It isn't affiliated with imput, the team behind Helium, or with Arc or Zen.

How can I help?

Try the prototype, star the repo, and open an issue when something feels slow or wrong. Calm and fast is the whole point, so those reports matter most.
